## 操作の仕方

- 枠内（白背景）: 参加者／admin の実操作ボタン
- 枠外上部: 画面切替・デモ用遷移（本アプリのUIではない）
- 枠内下部フッタ: プレイ中ステータス（名前・順位・仕事力・従業員・コイン／**ソリューション一覧・従業員一覧はボタン**）
- 準備画面（P-05）は約10秒で給与へ自動遷移（手動の「給与へ」ボタンは不要）
- 給与（P-06）は「確認」で同一画面内の確認待ち状態へ切替（別画面へ遷移しない）
- ソリューション詳細（P-11）は「決定」で同一画面内の効果反映状態へ切替（旧 P-12 効果確認は廃止）
- フェーズはパンくず `給与＞退職＞ソリューション＞採用` で示す（本文ヘッダに「○○フェーズ」を重複表示しない）

参加者: P-01 → P-02 → P-04 →（admin開始後）P-05 → P-06（確認→確認待ち）→ P-07 → P-08 → P-10 → **P-11（詳細→決定→効果反映）** → P-12 → P-13 → **P-14（詳細→合格通知を出す）** → P-15 → P-17 → … → P-20

Admin: P-01（隅）→ P-21 → P-22 → P-23 → P-24 → P-05
